# Releases

The signed APK (`com.newlang.french`, version 1.0.0) is produced by `./gradlew assembleRelease`.

Until a GitHub Release asset is attached (Actions needs the `workflow` token scope), install from the `dist/newlang-1.0.0.apk` built in this project or build locally with the committed keystore.

Tag target: v1.0.0
