# ניו לאנג · New Lang

מורה צרפתית אינטראקטיבית בעברית לאנדרואיד. לא שינון — שיחה, תיקון אמיתי, סלנג של בית קפה, ושיגרה של 15 דקות.

מאגר: [github.com/chesignup/new-lang](https://github.com/chesignup/new-lang)  
APK: [Releases](https://github.com/chesignup/new-lang/releases) — גם `dist/newlang-1.0.0.apk` בריפו.

**מזהה האפליקציה (קבוע):** `com.newlang.french`  
עדכונים מתקינים מעל הגרסה הקיימת. אין צורך להסיר ולהתקין מחדש, כל עוד חותמים עם אותו מפתח (`keystore/newlang-release.jks`).

## מה יש בפנים

1. **שיחה של 2 דקות** על חיי היומיום — מדברים, לא משננים.
2. **תרגום + 3 חידונים** על אותו משפט, עם הסבר לטעויות.
3. **בית קפה בפריז** — סלנג טבעי (`grave`, `nickel`, `t'inquiète`, `c'est ouf`).
4. **תיקון כתיבה** כמו מורה: מה שגוי, למה, ואיך מתקנים.
5. **10 משפטים מודרניים** שנשמעים בצרפת, לא בספר לימוד.
6. **שיגרת 15 דקות** — האזנה, דיבור, כתיבה. בלי שחיקה.

פלוס רצף, רמות, XP, תגים, והתראות מוטיבציה עם שעות שקטות (ברירת מחדל 22:00–08:00).

## OpenAI

בהגדרות מדביקים מפתח OpenAI. הוא נשמר **מוצפן** ב־Android Keystore / EncryptedSharedPreferences, לא בקוד ולא בלוגים.

מודל ברירת מחדל: **`gpt-4o-mini`** — מהיר לשיחה, מספיק חכם לתיקון. אפשר לבחור גם `gpt-4o`, `gpt-4.1-mini`, `gpt-4.1`, `o4-mini`.

בלי מפתח האפליקציה עובדת במצב דמו (תסריטי שיחה, משפטים, חידונים מקומיים).

## התראות

- תדירות: 1–3 ביום
- חלונות זמן לבחירה (בוקר / צהריים / ערב)
- שעות שקטות שלא מעירות בלילה

## בנייה מקומית

דרישות: JDK 17+, Android SDK 35.

```bash
echo "sdk.dir=$ANDROID_HOME" > local.properties
./gradlew assembleRelease
```

ה־APK החתום:

```
app/build/outputs/apk/release/app-release.apk
```

סיסמת ה־keystore המצורף לפרויקט האישי:

- קובץ: `keystore/newlang-release.jks`
- alias: `newlang`
- store/key password: `NewLangRelease2026`

אם מעלים לחנות ציבורית — צרו מפתח חדש ושמרו אותו בסוד. לפרויקט האישי הזה המפתח נשאר בריפו כדי שעדכונים ימשיכו להיחתם אותו דבר.
